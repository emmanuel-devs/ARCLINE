# ARCLINE — Canonical Visual Reference

**Source of truth:** the original ARCLINE architecture website design screenshot supplied by the owner in the ChatGPT project on 25 October 2026. Always compare proposed design and implementation against that original screenshot before changing the visual direction. Do not substitute a generic “premium architecture” aesthetic.

## Reference direction

- Clean, bright, contemporary architecture studio website.
- White / very light neutral backgrounds with restrained pale lavender-gray section backgrounds.
- Strong cobalt / electric-blue accent for buttons, numbered labels, and selected UI details.
- Dark teal / deep blue architectural hero photography with dramatic warm amber lighting.
- Crisp black sans-serif typography, compact navigation, rounded white contact button.
- Spacious, structured editorial layout with a clear grid and rounded-corner imagery/cards.
- Hero headline: “FROM CONCEPT TO BETTER LIVING”, arranged asymmetrically over the architecture image.
- Top navigation includes logo, Home, About, Service, Projects, Blog, and “Contact Us Now”.
- Hero includes short supporting copy and a “Book A Free Call” CTA.
- About section uses a left-side label and right-side explanatory copy, then a building image and testimonial/profile card.
- Services section: centered heading and six compact service cards in a three-column grid.
- Wide architecture/video image section with a centered play control.
- Metrics/testimonial panel with a dark metrics card, testimonial, and blue client-logo panel.
- Projects section with a pale lavender-gray background, strong heading, blue CTA, and asymmetrical project image grid.
- Articles/resources section follows below the visible reference area.

## Rules for future implementation

1. Treat the supplied original screenshot as the canonical design reference.
2. Preserve its color palette, layout character, visual hierarchy, component patterns, and image treatment unless the owner explicitly requests a redesign.
3. Do not default to the previous ivory + acid-lime cinematic concept. That was a divergence from the supplied reference.
4. Use architectural photography with a similar dark teal / amber hero mood and coherent project imagery.
5. Reproduce the visible structure and proportions before adding new sections or creative flourishes.
6. Check desktop and mobile separately; the reference screenshot primarily shows a desktop composition, so mobile adaptations should preserve its design language rather than copy desktop dimensions literally.
7. Do not claim pixel-perfect replication or award readiness without checking the live implementation against the reference.
