# ARCLINE

A cinematic architecture studio homepage built with Next.js 14, React, and TypeScript.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deployment

Import this repository into Vercel and keep the framework preset set to **Next.js**. Leave **Root Directory** empty and **Output Directory** unset (do not enter `public`). Vercel will detect Next.js and use the standard build output automatically.
